# 知屿 · Pro KB

按项目整理知识，用 Markdown 记录内容，用双向链接与关系图谱连接想法。界面采用固定黑灰深色玻璃风格，图谱使用细冰蓝连线，悬浮节点时突出关联关系。

项目和笔记保存在服务器 SQLite 数据库，浏览器不使用 localStorage。默认无需账号或密码，访问者可以查看、新建、编辑和删除内容。

在线访问：[http://106.54.43.240/kb/](http://106.54.43.240/kb/)。应用通过 `/kb/` 子路径与主机原有网站共存，已完成公网访问与保存验证。发布版本及验收记录见 [项目知识库](docs/kb/2026-10-10-首版实现与验证.md)。

## 启动

安装 Node.js **22.13 或更高版本**，在项目目录执行：

```sh
npm start
```

打开 `http://127.0.0.1:4173`。运行时没有 npm 依赖，也没有前端构建步骤；开发与测试工具才需要 `npm ci`。

首次创建数据库时生成三个演示项目：**CS7GV1.0（12 篇）**、**嵌入式开发（5 篇）**、**Linux 内核（5 篇）**。现有数据库不会被示例覆盖；CS7 摘要的来源与验证边界见 [示例来源](docs/DEMO_SOURCES.md)，基础教程的官方参考链接保留在各篇正文末尾。

## 能力

- 项目与笔记增删改查；标签、置顶、列表和卡片视图。
- 当前项目内按标题、正文和标签搜索，支持标签筛选。
- 基础 Markdown、`[[双向链接]]`、别名、标题锚点、反向链接和重命名引用更新。
- 图谱节点拖动、缩放、点击打开与关联高亮。
- 显式保存、Ctrl/Cmd+S、未保存提示、版本冲突保护；全部知识库 JSON 导出。

不同项目的数据与链接相互独立。当前提供共享知识空间，不包含账号角色、实时协同推送、JSON 导入或完整 Obsidian/CommonMark 功能。

## 验证

```sh
npm ci
npm test
npm run test:browser
```

浏览器测试默认使用已安装的 Chrome，自行启动隔离的测试服务；可用 `BROWSER_CHANNEL` 指定其他已安装的兼容通道。测试产物保存在 `artifacts/`。
