# 首版实现与验证

## 环境与范围

2026-10-10，工作区 `D:/mast/website`，Node 22.19.0，Windows Chrome 自动化验证。原生 JS + Node HTTP + SQLite；固定黑色/浅灰毛玻璃界面，默认免登录的共享可编辑空间。数据在服务器，浏览器不承担知识数据持久化。

CS7GV1.0 12 篇、嵌入式 5 篇、Linux 内核 5 篇，22 篇演示笔记全部站内引用可解析。来源快照与旧结论更正见 `docs/DEMO_SOURCES.md`，A 盘源文件只读访问。演示初始化仅发生在全新数据库，删除数据后重启不会重新补入样例。

## 已定位与修复

| 问题及复现 | 根因与处理 | 验证位置 |
| --- | --- | --- |
| 修改目标标题后，其他窗口可能写回旧引用 | 重命名事务同步更新关联文档的正文、时间与版本。所有受影响旧版本返回 409；前端保存后刷新项目列表。 | `server/store.js::updateNote`；`tests/server.test.js` 的 rename/revision 用例。 |
| 将标题 A 改为 A#B 会使链接变成章节引用 | 标题拒绝 wiki 保留分隔符 `[]#|` 与反斜杠；失败时事务不改变任何数据。 | 服务端 delimiter 回归。 |
| 从编辑项目弹窗打开删除确认，确认框瞬间消失 | 原生 dialog close 事件异步送达，被新弹窗处理器接收。同步结束旧 Promise，并忽略新弹窗仍打开时的旧 close 事件。 | `public/js/app.js::formDialog`；项目新增/修改/删除浏览器用例。 |
| 延迟 A 星标 PATCH 响应，切换 B 后 A 的版本写入 B，绕过 B 并发检查 | 星标返回未校验正在编辑的文档。统一 mutation 锁，响应校验项目及笔记身份，只更新对应草稿。 | `tests/browser.spec.js` 延迟 pin/delete/save 回归；修复前已复现覆盖 B 内容。 |
| 延迟删除 A 或加载其他项目，在等待时编辑 B/旧编辑器，响应结束丢失草稿 | 请求期间允许继续导航/输入，完成时无条件 resetEditor。导航和写操作共享忙碌守卫，期间禁用输入、格式工具和相冲突的操作；失败保留当前编辑。 | 延迟项目切换、删除及请求失败浏览器回归。 |
| 保存期间点击粗体，刚插入内容被成功响应覆盖 | formatText 绕过 saving 状态，脚本可修改 disabled textarea。函数及工具按钮都检查锁。 | 保存期间格式输入浏览器回归。 |
| 5000 个连续引用符触发 RangeError | Markdown blockquote 无界递归。递归最多 16 层，剩余内容转义为普通文本。 | `tests/markdown.test.js` 深引用回归。 |
| 50000 个未闭合左括号导致解析数秒、拖住服务器重命名 | wiki/Markdown 正则允许嵌套左括号，失败匹配出现平方回溯。禁止目标内左括号，扫描有界。 | 修复前约 4 秒；修复后 50k 测试约 1–3ms；domain/markdown 有时限断言。 |
| 十次正确登录后仍被限流 | 成功请求也累计失败额度。成功验证后清除失败计数。默认公开配置不经过登录。 | 服务端成功登录和限流回归。 |

## 验证

- `npm test`：31 项单元/HTTP/真实磁盘重开测试通过，含 SQL 隔离、事务回滚、请求限制、源文件隔离、可选会话与演示链接完整性。
- 浏览器覆盖：默认免登录、项目与笔记增删改、标题/标签/正文检索、Markdown、安全转义、双向引用及重命名、两独立浏览器读取服务器数据、409 草稿保留、请求竞争、图谱拖动/缩放/键盘导航、390px/320px 布局。
- 图谱悬停：选中及直接邻居明亮，其他节点 opacity 0.12；有关连线冰蓝 `#94caff`、0.75px，普通连线 0.45px，移开全部恢复。Node/edge data 仅来自当前项目。
- 新增 `/kb/` 同源反向代理浏览器回归：资源加载、POST 保存、刷新读取均通过。
- Node 22.19.0 的 `node:sqlite` 输出 ExperimentalWarning，这是运行时提示，不表示测试失败。

## 部署设计与边界

服务器已有网站占用 80 根路径，保留其代理到 3000。知识库使用 `/kb/`，Nginx 转发到本地 4173 并剥离前缀。系统 Node 20 保留，为本项目独立安装官方 Node 22.19.0，下载包 SHA256 已核对官方 SHASUMS。

数据路径独立于版本目录；部署不删除任何服务器文件。上线实测结果在完成后补记。

已实现基本 Markdown，不承诺完整 CommonMark 或 Obsidian 插件兼容；共享公开编辑无用户权限分级，非实时推送协作。跨浏览器再次加载可读取服务器最新数据。JSON 可导出，未实现导入。TLS 待域名/证书配置，当前入口使用 HTTP。
