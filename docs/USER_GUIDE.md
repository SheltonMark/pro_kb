# 使用说明

打开网站即可进入知识库，无需设置密码。所有访问者共享服务器中的项目和笔记，可以进行增删改查；保存后的内容可在其他浏览器重新载入查看。

## 项目与查找

左侧下拉框切换项目，“新建项目”建立独立空间；项目编辑可修改名称、说明与颜色，也可删除项目及其全部笔记。首次启动的默认项目是 CS7GV1.0，另有嵌入式开发和 Linux 内核两个基础教程项目。

“全部笔记”支持卡片与列表查看。搜索同时匹配当前项目的标题、正文和标签，多个词按同时匹配处理；点击标签进一步筛选。Ctrl/Cmd+K 可快速聚焦搜索。

## 编写与保存

点击“新建笔记”，填写标题、正文和标签；多个标签用中文或英文逗号分隔。笔记可置顶、修改和删除，正文支持编辑、阅读与分屏预览。

点击“保存”或按 **Ctrl/Cmd+S** 写入服务器。离开有修改的页面会提示处理未保存内容；若其他窗口已更新同一笔记，旧版本保存会被拒绝并保留当前草稿。先保留需要的文字，再重新载入最新版本并合并修改。

标题最多 180 个字符，不能包含 `[`、`]`、`#`、`|` 或反斜杠；同项目内不可使用归一化后相同的标题。正文上限 500000 个字符，每篇最多 20 个标签，每个标签最多 40 个字符。

## Markdown 与笔记关联

支持标题、粗体、斜体、删除线、列表、任务项、引用、代码块、基础表格、外链和 HTTP/HTTPS 图片。原始 HTML 按文字显示；这是基础 Markdown 编辑器，不支持完整 CommonMark 或 Obsidian 插件。

| 写法 | 效果 |
| --- | --- |
| `[[任务与中断]]` | 打开当前项目的同名笔记 |
| `[[任务与中断\|执行上下文]]` | 用“执行上下文”显示链接 |
| `[[任务与中断#快速响应，延后处理]]` | 打开笔记并定位对应标题 |

未创建的目标可通过链接进入创建流程。反向链接列出引用当前笔记的其他笔记。重命名会更新本项目的正文引用，保留别名与标题锚点；代码中的 wiki 示例不会被改写。

## 图谱与导出

图谱节点代表笔记，细冰蓝连线代表已存在的笔记关联。拖动节点或画布、滚轮缩放，点击节点打开笔记；悬浮节点时，其关联节点与连线保持突出。工具栏可缩放、复位和切换标签显示，键盘 Tab、Enter 也可选择并打开节点。

在“空间设置”选择“导出全部知识库”，下载包含所有项目与笔记的 JSON。当前提供导出，没有导入入口。界面固定为黑灰深色玻璃风格，不提供主题切换；内容不保存在 localStorage。
